AYOLAS WEB - INSTRUCCIONES

1. Reemplace las imágenes de ejemplo en la carpeta images por fotografías reales:
   portada-ayolas.jpg
   rio-parana.jpg
2. Mantenga las fotografías cuadradas 1:1 en las secciones indicadas.
3. Copie los PDFs finales a la carpeta pdf usando los mismos nombres de los enlaces.
4. Para publicar:
   - Netlify: arrastre la carpeta completa al panel de despliegue.
   - GitHub Pages: suba los archivos a un repositorio y active Pages.
   - Cloudflare Pages: conecte un repositorio o cargue el proyecto.
5. Cuando tenga la URL pública, genere un QR que apunte a la página principal.

IMPORTANTE:
OneDrive es adecuado para guardar PDFs, pero no es el alojamiento recomendado para un sitio web interactivo completo.
